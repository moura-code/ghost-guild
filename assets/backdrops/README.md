# Backdrops — placeholder

**These are AI-generated placeholders, not final art.** They were produced
locally with SDXL (see `tools/art/PROMPTS.md`), then desaturated, crushed dark
and blurred until only the suggestion of a place survives — at full strength a
generated image competes with the tower and the text in front of it.

They are deliberately easy to remove: `Atmosphere.set_biome` loads
`<biome_id>.webp` if it exists and shows nothing if it does not, so deleting a
file here degrades to the shader ground alone, which is a complete look on its
own.

Two things to settle before release:

1. **Replace them**, or
2. **Declare them.** Steam requires disclosing AI-generated content that ships.

Everything else in `assets/` is licensed third-party material credited in
`ATTRIBUTION.md`. This folder is the only exception, and it is not credited
because there is no author to credit.
