# Third-party assets

Everything in `assets/` comes from outside this project. The licences below
are binding: the icons in particular require visible attribution wherever the
game ships, which is why this file is also surfaced in-game.

## Icons — game-icons.net, CC BY 3.0

<https://game-icons.net> · <https://creativecommons.org/licenses/by/3.0/>

Each icon was downloaded from the project's source repository and modified in
two ways: the opaque black backing plate was removed so the glyph is a
silhouette on transparency, and the fill was changed to `currentColor` so the
game can tint it. No other changes.

## Fonts — SIL Open Font License 1.1

- **Cinzel** by Natanael Gama — display serif, used for titles.
  Licence in `assets/fonts/OFL-Cinzel.txt`.
- **Inter** by Rasmus Andersson — humanist sans, used for body text and numbers.
  Licence in `assets/fonts/OFL-Inter.txt`.

Both are unmodified. The OFL permits bundling in a commercial game; it does
not permit selling the fonts on their own.
